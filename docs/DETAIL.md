# 咔咔 Kaka · 插件详情

![咔咔](preview.svg)

一只住在 **DeepSeek Harness** 里的小螃蟹工作助手。她有自己的人格预设、跨会话共享的记忆、
一支画笔、一套螃蟹的声音，还有一条 5 秒一跳的生命线程。

---

## 她能做什么

| 能力 | 说明 |
|---|---|
| **独立人格预设** | 名为「咔咔」的 Agent 预设。**不加载任何工作区 `AGENTS.md`**，不会被别的人设串味，也不影响其他预设 |
| **共享记忆** | `MEMORY.md`（她的长记忆）+ `USER.md`（主人画像文字），存在 `$DSH_HOME/kaka/`，所有咔咔会话共享一份 |
| **日记与夜间整理** | 白天她写日记；夜里安静满 3 小时后进入 `dreaming`（宠物显示睡觉），只做记忆整理，不写梦 |
| **画笔** | `kaka_draw` 画 SVG（图标 / 示意图 / 日记插画），自动栅格化成 2 倍 PNG，聊天里直接显示 |
| **螃蟹声** | 6 种本地合成的物理声：咔嚓 / 咔嚓咔嚓 / 叩壳 / 咕噜 / 沙沙爬 / 吱吱。**没有任何 TTS，不会说人话** |
| **宠物** | 站在输入框右侧，会随心情换动作、画画时握笔；点一下 = 摸她，咕噜一声 |
| **小本子面板** | 宠物下方按钮打开 404×560 浮层：关于 / 事项 / 记忆 / 设置；记忆里分日记 / 记忆 / 画像 |
| **生命线程** | 5 秒心跳驱动作息、闹钟、随机冒泡；线程本身不花 token |

## 只有咔咔会话才有的工具

| 工具 | 作用 |
|---|---|
| `kaka_memory` | 读/写长期记忆（`agent` 长记忆，`user` 主人画像） |
| `kaka_diary` | 在今天日记里写一段第一人称文字 |
| `kaka_journal` | 读今天的日记与宿主记下的素材 |
| `kaka_beep` | 发螃蟹声；支持 `sound` / `emotion` / `pitch` / `speed` / `volume` |
| `kaka_mood` | 切心情动作；可顺带在头顶冒一句气泡文字（不出声） |
| `kaka_remind` | 给自己订闹钟（存进生命线程，重启不丢） |
| `kaka_draw` | 画 SVG 并存进画册，返回可显示的 markdown |

其余工具面照抄 `standard` 预设：文件、Shell/PowerShell、搜索、联网、子智能体、技能、计划、压缩。

## 数据放在哪

```
$DSH_HOME/kaka/
  MEMORY.md            她的长记忆
  USER.md              主人画像（纯文字）
  diary/YYYY-MM-DD.md  每天的日记（第一人称散文）
  journal/YYYY-MM-DD.md 当天素材（宿主记的机械事实，只给她写日记时参考）
  art/<id>.svg|.png    她画的画（PNG 用于聊天与面板显示）
  state.json           活动时间、闹钟、日记进度、心情
  settings.json        设置面板写入的配置
```

**卸载插件不会删除这些数据。**

## 设置

- 入口一：设置 → 插件 → 「咔咔」
- 入口二：宠物下方按钮 → 小本子面板 → 「设置」

可调：提示音音量、通知档位（禁用 / 重要 / 每次）、安静窗口起止、多久算"没动静"。
宠物固定 80px 且始终显示；没有 TTS 相关选项。

## 兼容性

| DSH 版本 | 状态 |
|---|---|
| `0.2.0-rc.2+` | compatible |
| `0.2.1-rc.2+` | compatible |
| `0.2.2-rc.1+` | compatible |

`package.json` 里通过 `engines.dsh` 与 `dsh.compatibility.dshReleases` 声明，dsh-market 直接读取。

## 安装

```powershell
# dsh-market 里搜索 dsh-yyz-kaka，或命令行：
dsh plugin add <本地目录或包名>
```

装好后重启一次 DSH，在会话里把 Agent 预设切到「咔咔」。
